# SQL-Assignment-2 SQL Employee Database Assignment

Project Overview

This project is based on an Employee Database created using MySQL.
The assignment covers SQL queries, data filtering, sorting, grouping, aggregate functions, and joins.

Topics Covered

* DISTINCT Values
* Alias using AS
* WHERE Clause and Operators
* ORDER BY
* LIMIT
* Aggregate Functions
* GROUP BY
* HAVING
* INNER JOIN
* LEFT JOIN
* RIGHT JOIN

SQL Tasks

The project includes queries to:

* Retrieve distinct employee salaries
* Use aliases for columns
* Filter employees based on salary and hire date
* Update missing designations
* Sort employees by department and salary
* Retrieve the first five employees hired in 2018
* Calculate total and minimum salary/age
* Find maximum salary for each location
* Calculate average salary for Analyst designations
* Find departments with fewer than three employees
* Find locations with female employees whose average age is below 30
* Retrieve employee, designation, and department details using INNER JOIN
* Display all departments and employee counts using LEFT JOIN
* Display all locations and assigned employees using RIGHT JOIN

Tools Used

* MySQL
* MySQL Workbench
* GitHub

Database Tables

* Employees
* Departments
* Locations

Purpose

The purpose of this project is to practice SQL querying and understand how to retrieve, filter, sort, group, update, and combine data from multiple tables.
